# Security

Report vulnerabilities privately through GitHub private vulnerability reporting: [open a report](https://github.com/aetelierxyz/aetelier-clarion/security/advisories/new), or use Report a vulnerability in the Security tab.

Do not open public issues or pull requests for vulnerabilities.

There is no bug bounty.

Scope: the on-chain program in `programs/clarion`, the crates in `crates/` and the formulae documents in `formulae/`. Reports apply to the latest release.
